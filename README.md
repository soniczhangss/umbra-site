# Umbra website

The support and privacy page for Umbra, a Safari extension for iPhone, iPad and Mac.

- Support URL: https://soniczhangss.github.io/umbra-site/
- Privacy Policy URL: https://soniczhangss.github.io/umbra-site/#privacy

It is one static page, `index.html` with `styles.css`, and has no scripts and no web fonts, so visitors' browsers request nothing from anyone but GitHub Pages. GitHub Pages serves it straight from `main`: commit, push, and the site updates within a minute or two. To look at it locally, open `index.html` in a browser.

When the privacy policy changes, update its "Last updated" date in `index.html`.
